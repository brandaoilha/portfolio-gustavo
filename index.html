Case #2

Automação de Relatório Diário de Vendas com Python

Desafio prático de automação: todos os dias o sistema atualiza as vendas do dia anterior, e o trabalho manual seria enviar um e-mail para a diretoria com o faturamento e a quantidade de produtos vendidos assim que o expediente começa. A proposta é automatizar essa rotina de ponta a ponta com Python e PyAutoGUI — buscando os dados disponibilizados pelo sistema e simulando as ações de mouse e teclado para compor e enviar o e-mail automaticamente, eliminando a tarefa manual repetitiva do início do dia.

  • Python
  • PyAutoGUI
  • Automação de Processos
